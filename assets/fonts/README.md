# Amiri Quran 1.003

`AmiriQuran.ttf` is unmodified from the 1.003 release of Khaled Hosny's Amiri:
https://github.com/aliftype/amiri/blob/1.003/fonts/AmiriQuran.ttf

SHA-256: `5594121cfcd33d05ea4635b7908d15c0eced0c91aa06469a95354b3369ca2949`

License: SIL Open Font License 1.1, included verbatim in `OFL.txt` from
https://github.com/aliftype/amiri/blob/1.003/OFL.txt.

The font is bundled on both supported platforms. Flutter's RTL TextPainter
shapes the unchanged ayah text, including diacritics, into transparent PNG
layers. The preview uses the same painter and fixed 1080×1920 coordinate system.
